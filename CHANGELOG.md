## [Unreleased]

### Added
- Core Architecture and API-first foundation.
- Authentication with scoped Bearer tokens stored in SQLite.
- Audit Logging subsystem.
- System metrics integration via `gopsutil`.
- Docker Engine SDK integration (containers, images, logs, stats).
- Dynamic Docker Compose Stack discovery and execution.
- System Power management (reboot/shutdown) with confirmation safeguards.
- Server-Sent Events (SSE) streaming for Docker and System updates.
- Documentation, CI/CD Actions, Dockerfile, and systemd units.
